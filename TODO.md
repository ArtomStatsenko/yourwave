# Отложенные задачи

- [ ] Ведущий заполняет паузы при загрузке YouTube Music.
  - При пустой очереди готовых песен коротко объясняет перебой по фактическому состоянию источника.
  - Использует настроенный контент и включённые интеграции, соблюдая существующий бюджет речи и частоту вставок.
  - Возвращается к музыке после завершения фразы, когда следующий трек готов.

- [ ] Смена названия станции через UI.
  - Поле названия станции в Settings вместо ручного изменения `broadcast.station_name` в конфиге.
  - Ведущий использует сохранённое название в следующих подводках.

- [ ] Назначение собственных джинглов через UI.
  - В Settings выбирать свои файлы или папки для каждой роли: вступление, концовка, подложка, разделитель, позывные, напоминания и заставки рубрик.
  - Сохранять назначения в локальном пресете Personal, сохраняя базовый набор репозитория.
