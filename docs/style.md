# Repository style

Yourwave uses a terminal-first, text-led presentation. The radio scale is the repository's static cover:

```text
──┬────┬────┬────▼────┬────┬────┬──
              YOURWAVE
```

- Use plain Markdown and monospace text for labels, commands, and small diagrams. Keep decorative art within 40 monospace columns so it stays legible on narrow screens. Unicode box-drawing characters are welcome.
- Prefer linked text for platform, license, and release information. Avoid decorative badges, oversized word art, gradients, generated raster covers, and animated banners.
- Keep navigation, headings, lists, and tables readable. Do not turn instructions into an imitation terminal transcript or frame every paragraph in a box.
- Use actual interface screenshots when they explain the product. Label demo data, exclude private content, and support light/dark themes when useful.
- Follow the application's existing restrained palette when color is necessary. Let GitHub's theme control the appearance of text and code blocks.
- Adapt public-facing presentation for an English-speaking audience, including default host names, character descriptions and setup examples. Preserve personal station choices in private local overrides. Existing separate historical documents may remain in Russian; source-language examples and broadcast prompts retain the language they need.
- Describe implemented behavior and real status only. Keep setup requirements and audio licensing visible.

This guide governs repository presentation; it does not request a redesign of the application or changes to broadcast behavior.
